# Game info

The game design lives here: setting, art style, the assets list, mechanics.
This is the input to the pipeline in `CLAUDE.md`. `concept-artist` and `game-builder` read it.

Suggested files:
- `game.md`: pitch, core loop, controls, win/lose conditions
- `art-style.md`: palette, mood, level of detail, reference adjectives
- `assets.md`: one entry per asset (name in kebab-case, description, size, role in the game)
