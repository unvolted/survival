# Reports

One report per agent per task, named `<YYYY-MM-DD>_<Agent>_<Task>.md`
(for example `2026-11-07_ConceptArtist_StyleGuide.md`, `2026-11-07_GameBuilder_M0.md`).

```markdown
# <Agent> — <Task>

## Done
What was produced (file names).

## Verified
How each item was checked. Anything that could not be verified is listed here as NOT verified, with the reason.

## Assumptions
Anything decided without a clear spec.

## Blocked
What is missing and who must fix it.

## Next
What the next agent needs to know.
```

Game-builder milestone reports also include test results, frame-time numbers and known bugs.
